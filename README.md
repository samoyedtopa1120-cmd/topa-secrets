## 🛠 整理方式

1. 下載直播音訊，用 OpenAI Whisper 自動轉成逐字稿
2. 逐場閱讀逐字稿，挑出多帕講自己的內容
3. 排除念觀眾留言、棉花糖投稿、遊戲台詞，以及連動中分不清說話者的句子
4. 合併在不同場次重複提到的內容，並逐一核對時間軸

## 🙅 刻意不收的內容

這裡只收多帕以 VTuber 身分分享的事。下面這些即使直播中提過，也都沒有收錄：

- 能辨識真人身分的資訊，例如本名、居住地、學校、工作、家人細節、具體行程
- 心理健康、醫療檢查、手術、事故等私密話題

## ⚠️ 注意事項

- 逐字稿是自動轉錄的，可能有聽錯或錯字，**一切以直播影片為準**。
- 問答檔的答案就寫在每題下方。如果要拿來考粉絲，建議只複製題目和選項出題。
- 如果發現資料有誤，或有內容不希望公開，歡迎開 Issue 告知。
